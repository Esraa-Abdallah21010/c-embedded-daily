# Hello World

- **Date:** 2026-11-14
- **Source:** [Codeforwin](https://codeforwin.org/c-programming/hello-world-program-c)
- **Problem:** Write a first C program that prints "Hello, World!" to the screen.
- **Approach:** Included `stdio.h` to get access to `printf()`, then called `printf()` inside `main()` and returned 0 to signal successful execution.
- **What I learned:** The basic structure of a C program (`#include`, `main`, `return 0`), and how `printf()` prints text, including `\n` for a new line.
