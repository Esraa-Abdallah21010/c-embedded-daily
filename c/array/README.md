# Array

Exercises from [w3resource - C arrays](https://www.w3resource.com/c-programming-exercises/array/index.php).

| File | Problem | Notes |
|------|---------|-------|
| [array_store_print.c](array_store_print.c) | Read 10 integers into an array and print them. | The return value of `scanf` is checked on every read. |
| [array_reverse.c](array_reverse.c) | Read n values into an array and display them in reverse order. | Reverses in place by swapping `Arr[i]` with the element at the other end, moving both towards the middle, so each pair is swapped once. The count is read with `%hhu`. |
| [array_sum.c](array_sum.c) | Read n values into an array and print the sum of all elements. | Practice combining functions with arrays: one function fills the array and another sums it |
| [array_copy.c](array_copy.c) | Copy the elements of one array into another array and print both. | Practice combining functions with arrays: one function copies element by element into a second array, and the source is passed as `const` because it is only read.|
| [count_duplicate_elements.c](count_duplicate_elements.c) | Count the total number of duplicate elements in an array. | An element is counted if the same value appears again later in the array, so `5 5 5` gives 2. The inner loop stops at the first match (`break`), so each element is counted at most once. The element count is not range-checked. |
| [print_unique_elements.c](print_unique_elements.c) | Print the unique elements (values that appear exactly once) of an array. | Each element is compared with all the others; if no equal element is found it is copied into a second array, and the number of unique elements is returned through a pointer parameter. The second array costs extra memory the size of the input. The element count is not range-checked. |
| [merge_two_sorted_arrays.c](merge_two_sorted_arrays.c) | Merge two arrays of the same size and print the result sorted in descending order. | Both arrays are copied into a third array, which is then sorted with an exchange sort in a single pass. The total count is held in a `u32` and the loop counters match it, because two `u8` counts can add up to more than 255. The counts themselves are read with `%hhu` and not range-checked (0 is not rejected). |
| [frequency_of_array.c](frequency_of_array.c) | Count the frequency of each element of an array. | Each value is printed once: an element is skipped if the same value appeared earlier, otherwise its occurrences after it are counted. Nested loops, so it is quadratic. The element count is not range-checked (0 and values above 255 are not rejected). |
| [find_maximum_minimum.c](find_maximum_minimum.c) | Find the maximum and minimum elements in an array. | Both start from `Arr[0]` instead of 0, so arrays with only negative values work. An element count of 0 is rejected in `main` before the array is created. Each function returns an error state (`NULL` pointer) and delivers the result through a pointer, so a result of 0 can't be confused with an error. The count is read with `%hhu`, so values above 255 wrap around. |
| [separate_odd_even_arrays.c](separate_odd_even_arrays.c) | Separate the odd and even elements of an array and print each group. | Counts the even elements first, then prints the even and the odd elements in two passes over the input, without a second array. The input is unsigned, so a negative value wraps around. The element count is read with `%hhu` and not range-checked. |
